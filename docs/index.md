# Bandcamp Sync documentation

This folder has the documentation for Bandcamp Sync. Bandcamp Sync is a
command-line program that downloads albums from Bandcamp to a local folder.

## Pages

- [Installation](installation.md) — install the program and its dependencies.
- [Usage](usage.md) — use the `download`, `sync` and `fan-id` commands.
- [How it works](how-it-works.md) — the cache, the sync steps and the rate
  limit control.
- [Development](development.md) — set up the code, run the tests and run the
  checks.

## First steps

1. Read [Installation](installation.md) and install the program.
2. Read [Usage](usage.md) and run your first command.

## About this documentation

This documentation uses ASD-STE100 Simplified Technical English. The text uses
short sentences, the active voice and the simple present tense. Each procedure
step is one instruction.
