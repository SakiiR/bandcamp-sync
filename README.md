# Bandcamp Sync

bandcamp-sync is a python program. It synchronises your bandcamp wishlist locally with album cover art and other meta datas.

It uses a cache system to eases the synchronisation and make it incremental. 

You can add a single item to your wishlist, and it will never be downloading anything else than this new item.
